# ADR 001: 독립 애플리케이션으로 분리한 이유

## 상태
Accepted

## 결정
SubForge를 DriveAtlas의 add-in이 아니라 독립 데스크톱 애플리케이션으로 설계한다.

## 근거
- 파일 관리와 AI media processing 책임 분리
- Whisper/ffmpeg/translation 의존성 분리
- 장시간 Job lifecycle 독립 관리
- SubForge 단독 실행 가능
- 향후 DriveAtlas 외부 실행 인터페이스로 연동 가능

## 결과
SubForge는 자체 DB와 큐를 가진 독립 프로세스로 유지한다.
