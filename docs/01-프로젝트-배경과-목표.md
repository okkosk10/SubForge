# 01 프로젝트 배경과 목표

## 배경
DriveAtlas에서 파일 탐색과 관리는 해결했지만, 외국어 미디어 처리에는 별도 반복 작업이 남아 있었다.

- 음성 인식
- 번역
- 자막 생성
- 결과 검수

기존 개인 자동화 도구는 폴더 단위 배치 처리였고, 장시간 실행 중 일부 실패 파일의 재처리/이력 추적이 어려웠다.

## 문제 재정의
SubForge는 폴더 배치 중심이 아니라 파일 단위 Job 중심으로 문제를 재정의한다.

- Folder Batch Processor
- Persistent File Job Queue

## Iteration 01 목표
AI 기능 구현 이전에, 다음 기술 골격을 검증한다.

- Electron 데스크톱 구조
- Job 도메인 모델
- SQLite 영속성 및 migration
- Persistent queue 설계
- Main/Preload/Renderer 경계
- 확장 가능한 문서 체계

## 비목표
Iteration 01에서는 STT/번역/SRT 생성을 구현하지 않는다.
