# 05 기술 검토와 선정

## Electron
데스크톱 파일 접근, native dialog, 장시간 Job lifecycle 제어를 위해 Electron 채택.

## React + TypeScript + Vite
초기 생산성과 타입 안정성 확보를 위해 선택.

## SQLite
로컬 단일 사용자 앱에 적합한 임베디드 DB.
- 상태 영속성
- 이벤트 이력
- 향후 segment 저장

## 설계 원칙
- Repository: SQL CRUD 담당
- Service: 검증/도메인 규칙
- IPC Handler: 요청 전달 및 응답 매핑
- Scheduler: 단일 동시성 정책 분리
