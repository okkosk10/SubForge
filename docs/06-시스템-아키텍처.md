# 06 시스템 아키텍처

## 프로세스 계층
Renderer (React)
-> Preload (typed IPC bridge)
-> Main (Electron)
-> Job Service / Queue Scheduler / SQLite
-> (향후) Python Worker

## 현재 구현 범위
- Renderer: Jobs/New Job/Job Detail/Settings
- Preload: `jobs.*`, `files.selectMedia`
- Main: BrowserWindow, IPC 등록, DB 초기화
- Domain: Job 중심 모델, queue 정책

## 확장 경계
- Worker 실행은 Scheduler의 TODO boundary에서 연결
- Pipeline step 상태는 DB 필드로 선반영
- Segment 테이블은 향후 STT/번역 결과 저장용으로 예약
