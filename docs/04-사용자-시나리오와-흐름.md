# 04 사용자 시나리오와 흐름

## 시나리오 A: 단일 Job 생성
1. 사용자가 New Job 화면 진입
2. Add File 클릭
3. native file dialog로 영상 파일 선택
4. source language 선택 (예: Japanese)
5. Create Job 클릭
6. Jobs 화면에서 WAITING 확인
7. Job Detail에서 메타데이터/이벤트 확인

## 시나리오 B: 다중 파일 큐 적재
1. 사용자가 여러 파일을 반복 등록
2. 각 파일별 독립 Job 생성
3. 목록 예시
   - A.mp4 WAITING
   - B.mp4 WAITING
   - C.mkv WAITING

## 시나리오 C: 재실행 복원
1. 앱 종료
2. 앱 재실행
3. 이전 jobs와 events가 그대로 조회됨
