# 07 데이터 설계

## DB 위치
Electron `app.getPath('userData')` 하위 `subforge.sqlite3`.

## Migration 정책
- `schema_migrations` 테이블로 버전 추적
- 기존 migration 수정 금지
- 변경 시 새 migration 추가

## jobs
- id (PK)
- source_path
- output_path
- source_language (ja/en/ru/zh)
- target_language (기본 ko)
- status (WAITING/RUNNING/COMPLETED/FAILED/CANCELLED)
- current_step (nullable)
- progress (0~100)
- error_code, error_message (nullable)
- created_at, started_at, completed_at, updated_at

## segments
- id (PK)
- job_id (FK jobs.id)
- sequence
- start_ms, end_ms
- source_text, translated_text
- created_at, updated_at

## job_events
- id (PK)
- job_id (FK jobs.id)
- step (nullable)
- level (INFO/WARNING/ERROR)
- message
- created_at

## 제약
- Foreign key 활성화 (`PRAGMA foreign_keys = ON`)
- progress range check
- enum 값 check
