# 02 요구사항 정의

## 제품 원칙
- 파일 1개 = Job 1개
- 여러 파일 등록 시 각각 독립 Job 생성
- WAITING/RUNNING active 중복 방지
- 실패 Job 삭제 금지, History 보존
- 앱 종료 후 상태 복원
- AI 동시 실행 수 1

## 언어 범위
- Source: ja, en, ru, zh
- Target: ko

## 보안/경계
- `contextIsolation: true`
- `nodeIntegration: false`
- Renderer는 Node/fs/SQLite 직접 접근 금지
- IPC로 필요한 최소 기능만 노출

## Iteration 01 사용자 기능
- New Job 화면에서 Add File
- source language 선택
- Create Job
- Jobs 목록에서 상태 확인
- Job Detail 확인
- 재실행 후 동일 Job 복원

## 지원 확장자
- .mp4
- .mkv
- .mov
- .avi
- .wmv
